# LogForge
LogForge A lightweight, pure-Python log parsing and financial structured report generation tool.
Project Highlights & Technical Features
1 Zero External Dependencies: Built entirely with native Python built-in libraries and standard syntax for clear underlying logic.
2 High-Precision Financial Settlement: Explicitly uses decimal.Decimal instead of standard float for currency handling to eliminate precision loss span_19span_19.
3 Strict Alignment Formatting: Applies precise string formatting placeholders (%-15s, %10.2f) to output perfectly aligned structured text reports span_20span_20.#
4 Memory Safety & Compliance: Implements the with open context manager for safe file I/O operations span_21span_21.
5 Clean Repository Architecture: Pre-configured .gitignore automatically excludes .pyc bytecode files and __pycache__ folders span_22span_22.
Quick StartRun the main script directly from your terminal:bash python logforge.py



LogForge는 경량화된 순수 Python 기반의 로그 파싱 및 재무 구조화 보고서 생성 도구입니다.

프로젝트 주요 특징 및 기술적 강점
외부 의존성 제로 (Zero External Dependencies): 순수 Python 내장 라이브러리와 표준 문법만으로 구축되어 내부 로직이 명확합니다.
고정밀 재무 정산: 통화 처리 시 일반적인 float 대신 decimal.Decimal을 명시적으로 사용하여 정밀도 손실을 방지합니다.
엄격한 정렬 포맷팅: 정밀한 문자열 포맷팅 자리 표시자(%-15s, %10.2f)를 적용하여 완벽하게 정렬된 구조화 텍스트 보고서를 출력합니다.
메모리 안전성 및 규준 준수: with open 컨텍스트 매니저를 구현하여 안전한 파일 I/O 작업을 수행합니다.
깔끔한 리포지토리 아키텍처: 사전 설정된 .gitignore를 통해 .pyc 바이트코드 파일과 __pycache__ 폴더를 자동으로 제외합니다.

빠른 시작 (Quick Start)
